## Descripción del trabajo 
En este proyecto desarrollé la maquetación de una web portfolio que funciona también como Curriculum Vitae personal. Tomé como inspiración webs que nos compartieron de referencia y a su vez visité plataformas como Pinterest,para entender la estructura y diseño de la misma. La web consta de:

* **Index:** El index es sencillo es un video introductorio generado con IA con un título, breve descripción y 2 call to action
* **Sobre mi:** Esta sección describe mi perfil con acceso, a través de pop-ups, a mis experiencias laborales junto a un scroll infinito mostrando los íconos de las herramientas que uso.
* **Trabajos:** Esta sección, a partir de una galería de imágenes, muestra mis trabajos. Haciendo clic en ellas, se abren pop-ups con información del trabajo, más imágenes del mismo y un link a Behance del proyecto. Haciendo clic en las imágenes del pop-up se abren nuevamente pero en un tamaño más grande.
* **Header y Footer:** El header tiene un nav con las tres secciones más un botón que te dirige a mi Whatsapp. El footer tiene un formulario para llenar cargando datos personales para que yo pueda escribirte.
